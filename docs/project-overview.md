# Project overview

## Academic purpose

This repository supports the undergraduate final project **DDoS Attack Detection and Response System in SDN Networks with Open Source Tools** at Universidad del Valle.

The general objective is to design and simulate a mechanism to detect and respond to DDoS attacks in SDN networks under business scenarios.

## Research question

How can an SDN efficiently detect and mitigate DDoS attacks against its centralized controller while preserving legitimate service performance and keeping implementation costs low?

## Specific objectives

1. Characterize SDN vulnerabilities that facilitate DDoS attacks and analyze their business impact.
2. Simulate an SDN network with intrusion and DDoS detection mechanisms.
3. Evaluate detection and response behavior under different simulated traffic conditions.

## Expected evidence

Experiments should report detection rate, false-alarm rate, precision, recall, F1 score where labels permit them, average detection time, latency, throughput, packet loss, CPU/RAM usage, and recovery time. Every result must state the topology, traffic generator, baseline, attack window, recovery window, software versions, and configuration values used.
