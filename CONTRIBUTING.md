# Contributing

1. Explain the research or reproducibility reason for the change.
2. Keep experiments isolated and bounded; do not add public-target tooling.
3. Add deterministic tests for changed behavior.
4. Update the relevant guide, `.env.example`, and current-status table.
5. Run `make check` and report any manual Mininet validation separately.

Use focused commits and do not include PDFs, credentials, proxy lists, logs, captures, environments, or model binaries unless their provenance and license have been reviewed and documented.
